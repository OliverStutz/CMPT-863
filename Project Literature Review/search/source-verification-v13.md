## 3. Differences found

None that require a change to the reference list. Notes for the author's judgement:

- **#10 Gupta 2026, author 2.** Crossref records family name "Victoria Aritonang", given name "Nadia". The paper itself (arXiv title page and its ACM reference line) writes "Nadia Victoria Aritonang". The entry's "Aritonang, N. V." follows the paper and is the usual reading; if you prefer to follow the DOI metadata it would be "Victoria Aritonang, N." No change recommended.
- **#20 Mayer 1995, pages.** Crossref holds only the first page (709); the JSTOR title page of the local copy confirms 709-734. Entry correct.
- **#22 Microsoft n.d.** No date is visible on the page; the HTML metadata has ms.date 12/23/2025. "n.d." with a retrieval date is correct APA. The live URL slug says "microsoft-365-copilot" while the page title says "Microsoft Copilot"; the entry uses the page title, which is right.
- **Online-first vs issue year** (#13 Kempt, #24 Pezzo, #25 Prike, #28 Sharma): online-first dates fall a year earlier than the entry year; the entry year matches the issue (published-print) year, which is what APA 7 uses when volume and issue are given. No change.

## 5. Method

Working directory for downloads: `/tmp/claude-1000/-mnt-RAID-STORAGE-SFU-Projects-CMPT-863-Project-Literature-Review/760bb351-b797-4384-ae74-f1c70664ff41/scratchpad/source-check/` (subfolders `crossref/`, `web/`).

```bash
# Local copies: title page check
pdftotext -l 2 "references/<file>.pdf" - | head -60
head -20 "references/<file>.txt"

# Crossref, one call per DOI, 1 s pause
curl -sL -A "LitReviewCheck/1.0 (mailto:oliver.stutz@priverion.com)" \
  -o crossref/N.json "https://api.crossref.org/works/<DOI>"; sleep 1
# fields compared (python3 -I): title, subtitle, author family/given, container-title,
# issued, published-print, published-online, volume, issue, page, article-number, publisher

# Non-DOI pages
curl -sL -A "Mozilla/5.0" -o web/wN.bin -w "%{http_code} %{url_effective}\n" "<URL>"
grep -oE '<title>[^<]*</title>|"datePublished":"[^"]*"|name="author" content="[^"]*"|ms.date" content="[^"]*"' web/wN.bin

# Fallbacks for blocked sites
curl -sL -A "Mozilla/5.0" "https://web.archive.org/web/2025/https://eur-lex.europa.eu/eli/dir/2022/2555/oj"
curl -sL -A "Mozilla/5.0" -o wb5.pdf "https://web.archive.org/web/2024id_/https://www.sec.gov/files/rules/final/2023/33-11216.pdf"
pdftotext -l 1 wb5.pdf - ; cmp wb5.pdf references/SEC-2023-cybersecurity-disclosure-final-rule-33-11216.pdf
curl -sL "https://www.federalregister.gov/api/v1/documents.json?conditions%5Bterm%5D=%2233-11216%22&fields%5B%5D=title&fields%5B%5D=citation&fields%5B%5D=docket_ids&fields%5B%5D=publication_date"
```

All 26 DOIs returned Crossref HTTP 200, so the doi.org and OpenAlex fallbacks were not needed.
