Checked 2026-10-20 by an Opus agent (brief REF-B, `../slides/_agent-briefs.md` Part 5). Scope: every work outside Gaver 2012 named in `01-Background.md` to `11-Discussion-Bridge.md` (slides, Say, Watch out, If asked, Background, Sources, logs), deduplicated across files. Course readings held as local PDFs were checked for bibliographic data only (Crossref), not for quotations. The paper's own reference list is covered in `opus-REF-paper-references.md` and is not redone here; where our files repeat one of its errors, that is flagged.

Method: Crossref API for every DOI and for title queries where no DOI was given (`https://api.crossref.org/works/<DOI>` or `?query.bibliographic=`); every URL in the files (159 unique) was fetched by script, with redirects followed, and its title or first page checked against the work claimed. Blocked fetches were retried with a second user agent and the Wayback Machine, and a second source is named where they still failed.

Verdicts: **OK** (matches the source), **wrong** (a factual error, with the correct data), **unverifiable** (no source reached). "URL note" marks a URL that is blocked or no longer leads to the work, although the data itself is confirmed elsewhere.
